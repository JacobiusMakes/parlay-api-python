# Support

ParlayAPI is founder-run. Questions and bug reports land directly with the person who wrote the code, and replies are usually same-day. That is what usually happens, not a guaranteed SLA.

## Where to go

- **Bug reports:** [open an issue](https://github.com/JacobiusMakes/parlay-api-python/issues). Confirmed bugs usually get a fix the same day.
- **Questions and ideas:** [GitHub Discussions](https://github.com/JacobiusMakes/parlay-api-python/discussions)
- **Email:** support@parlay-api.com
- **Docs:** https://parlay-api.com/docs

## What helps

For bugs, a minimal snippet that reproduces the problem plus your `parlayapi` package version and Python version gets you the fastest turnaround.
